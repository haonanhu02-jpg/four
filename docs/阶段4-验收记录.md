# 第四阶段：自动顺延、跨年承接与历史复盘

日期：2026-10-22。代码目录：`D:/download/ws-p`。本阶段在本地完成，未接入或发布 GitHub 仓库，第五阶段尚未开始。

## 顺延行为

| 事项 | 过期条件 | 当前排期调整 |
| --- | --- | --- |
| 日待办 | 未完成，执行日期早于账号今天 | 调到今天 |
| 周任务 | 状态不是已完成，实际结束日期早于账号今天 | 调到当前自然周，周一至周日 |
| 月度目标 | 手动进度不足 100%，所属月份早于当前月份 | 调到本月 |
| 年度目标 | 不自动顺延 | 年份、内容及关联由用户管理 |

自然周期与自定义周区间均按实际结束日期判断。本周内提前结束的区间也能识别过期；顺延后结束日落到周日，不会在同一天反复顺延。已完成、已删除或已归档事项不移动。

每次顺延沿用原事项 ID，递增版本和顺延次数；原始年月日/区间、截止日、标题、手动进度、权重、优先级、受阻等状态和关联保持。停用多日后直接移入当前周期，不逐日复制事项。截止日不随排期延后，原有逾期提示继续有效。

## 执行与并发

- 服务端定时扫描和访问时补偿共用 `RolloverService.reconcile`。定时每 15 秒取最多 50 个账号，每个账号每次最多处理 100 条；账号较多时分批轮转，不宣称所有账号在同一秒执行。
- 前端载入工作台前检查，单次载入最多连续补偿 10 批，剩余事项由后续访问或定时继续处理。恢复已删除的旧事项后，重新载入会补偿其过期排期。第五阶段导入/离线队列接入同一补偿入口，当前没有虚构导入功能。
- 页面每分钟以及返回前台、恢复网络时先处理未保存修改，再检查周期。自然当前视图跨天可以跟随今天；历史日期、自定义查看区间和历史复盘不会被强行切走。新会话仍默认今天。
- 今天由服务端时钟结合用户时区计算，默认 Asia/Shanghai；业务日期与 UTC 时间戳分别保存。公开接口不接受客户端指定“今天”。
- 与日常增删改共用账号事务锁，同时锁行并按版本更新。状态与过期条件重新检查，同一账号多端或多实例重复检查只产生一次有效顺延。
- 事项更新、次数、排期日志、来源快照、跨年提示及检查状态在事务中提交；任一步失败整体回滚。后台拿不到锁时跳过，下一轮或访问时再补偿。
- 顺延前先封存各源周期，并保存整批变更前的来源链，避免父项先移动后，下级历史混入新排期。顺延与手动调整排期都写入可分页查询的排期记录。

## 跨年承接

跨年未完成月目标进入当前月份后，保留原年度关联，并出现“跨年承接待确认”。提示也覆盖当前月份已调整、但仍挂在旧年度下的未完成月目标。

用户可以保留当前关联，或明确选择目标年份内的年度目标并确认改挂。改挂只更新月目标的直接关联，周、日身份和关联不复制，年度归集随完整链路重新计算。旧来源保留在承接记录、审计日志及已封存周期中。

确认接口检查账号、目标年份、有效父项和事项版本，操作编号支持幂等重试；旧版本或另一页面已处理的确认要求刷新。直接在卡片里修改关联也保留编辑日志，并在补偿检查时更新确认状态。旧年度未处理提示在更晚年份由新的承接提示取代。

## 历史复盘

- “历史复盘”入口提供周期复盘及排期/顺延记录；事项卡片另有本事项排期记录入口。
- 按年、月、周/自定义区间、日选择封存周期，按层级和已完成/未完成筛选，周期、事项与排期记录均分页。
- 封存内容只读，包含当时的标题、进度/状态、排期、原计划、截止日、顺延次数和完整上级来源。后续编辑、删除、恢复或改挂不会改写已有非空快照。
- 封存数据通过独立明细表保存，读取分页；不在每次打开页面时把整年 JSON 下发到浏览器。日周期包含当日待办；周包含相交周任务及区间内待办；月包含该月目标、相交周任务及月内待办；年包含该年目标及对应日历范围内事项。父级完整信息另外随每条事项封存，不重复当成执行数。
- 自动检查会处理源周期、最近结束自然周期和上次检查所在的已结束周期。空自动检查不留下空快照，避免阻止后续恢复的旧计划被捕获。
- 未封存的已结束周期可“补充封存”，明确以现存数据及实际捕获时间为准；不冒充周期结束时的精确还原。显式封存的空周期也保留，已有封存不覆盖。开放周期不能提前封存，自定义补充区间最多 366 天。
- 启用前已经被改写、且没有日志或快照的旧数据无法凭空还原。已完成事项的原排期仍保留在业务表，需要时可补充封存。

## 数据与接口

新增迁移 `0002_rollover_history.sql`：日/周/月顺延次数、封存明细、账号检查状态及跨年承接表，复用已有排期日志和操作日志。不修改已应用的第一阶段迁移。

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/rollover/reconcile` | 基于服务端今天补偿检查，返回分层次数、剩余量和待确认量 |
| GET | `/api/rollover/carryovers` | 分页查询待确认承接 |
| POST | `/api/rollover/carryovers/:id/resolve` | 带版本与操作编号确认保留或改挂 |
| GET | `/api/history/periods` | 按周期类型分页列出封存 |
| POST | `/api/history/periods` | 补充封存一个已结束周期，不覆盖既有记录 |
| GET | `/api/history/periods/:id` | 按层级和完成状态分页读取只读事项 |
| GET | `/api/history/changes` | 按事项/层级分页读取顺延及手动排期记录 |

所有接口按有效会话隔离账号，并校验旧浏览器账号标头、UUID、分页、枚举和日期。测试用时钟只在进程内替换，生产 API 没有修改时钟的入口。
