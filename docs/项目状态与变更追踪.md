# 项目状态、初始计划与周安排

年度、月度目标和周任务支持带数量的“全部、未完成、进行中、已完成、未开始、已终止”筛选。目标状态按实际进度判断；周任务保留原有未开始、进行中、受阻和已完成状态。终止与删除、完成独立，终止项仍可查看、编辑原因及恢复，不计入有效进度和权重，不再自动顺延。终止只作用于本事项，不自动终止或删除其下级。

年度视图下方“项目变动情况”读取当前账号已有的操作日志，展示最早留存记录、当前内容和逐次修改时间、字段前后值。没有年初记录的旧数据不补造年初计划。

登录并同步完毕后，可确认当前年度目标与年初计划一致，再点击“记录年初计划基线”。基线保存当时的服务器快照，重复请求不会覆盖；后续新项目标为基线后新增，删除、终止及移出本年度的项目仍可对照。基线及日志按账号隔离，包含在数据库完整备份中；项目 JSON/表格文件保留终止状态及原因，年初基线和审计日志独立保存在云端，不属于事项文件导入替换的内容。

周视图自动汇集所选月份及跨月周区间涉及的未完成月目标；没有关联本周有效周任务的目标在底部展开区提醒，可查看月目标或点击“安排本周任务”。查看页面不创建重复周任务。

没有有效周关联、但日期在所选区间内的每日工作，统一放到“未挂周任务的待办 N 条”，显示所选日期的剩余数，可展开查看和关联。完成记录保留，终止项不计入今日剩余。

本次数据库迁移为 `0008_project_termination.sql`，旧事项默认未终止。访客支持本机状态与待办操作；年初基线及完整项目变更审计需登录同步后查看。
