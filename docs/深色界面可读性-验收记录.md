# 1.1.1 深色界面可读性修复

根据登录示意卡、尚未添加事项的占位区域，以及数据管理关闭按钮的浏览器反馈修复。

- 登录页行动路径卡片和年/月/周/日空状态原先使用固定半透明白底。深色模式中该背景与浅色文字混合，浏览器实测部分文字对比度分别低至 1.10:1 和 1.82:1；改为随主题切换的实色表面。
- 空状态标题使用正文颜色，说明使用次级文字颜色，新增入口使用链接颜色；浅色与深色均检查，不通过给整个卡片加透明度处理。
- 数据管理、导出和账号管理共用新的关闭按钮。右上角使用中性的圆形点击区域与线条 SVG，提供悬停、按压和键盘焦点反馈；桌面 36 × 36，手机 44 × 44，保留明确的读屏标签和忙碌时禁用行为。
- 浏览器回归覆盖两种主题的登录卡片与四层空状态，计算文字实际合成背景上的对比度，要求不低于 4.5:1，并检查关闭按钮形状、位置、手机尺寸和页面溢出。继续执行主题切换、系统主题、离线草稿和 Service Worker 更新保护验证。

复现截图和修复后截图由 `tests/browser-stage6.mjs` 输出到指定的 `BROWSER_ARTIFACT_DIR`；CI 保留脱敏截图与 `readability-check.json`、`browser-check.json`。功能、账号和数据库模式未变化，数据库仍由原持久卷保存。

本次同时将已经验证的一键部署脚本、Windows/Linux 包装器和操作说明纳入 1.1.1 完整发布包，并提供独立附件。部署脚本取得最新正式版的对应源码与镜像，避免更新时重新载入旧界面。
