# 工号登录改造：1.0.1

日期：2026-10-28。本次将注册和登录改为工号与密码，不再要求邮箱或验证码。登录、注册均显示“请输入您的工号”，密码最低 6 位，接受纯数字等任意字符组合，保留 128 位长度上限。新账号注册成功后直接进入工作台。

工号按文本存储，保留前导零，忽略首尾空白和英文字母大小写；不能包含内部空白字符。重复工号在数据库中唯一，注册冲突返回明确提示，错误密码继续受到请求频率限制。密码继续使用 scrypt 哈希，登录继续使用 HttpOnly 会话 Cookie。

迁移 `0005_employee_login.sql` 为旧账号保留原登录名、用户 ID、密码和业务数据；本地已有 2 个旧账号，按用户确认保留原名，后续再绑定工号。旧账号暂在工号框输入原登录名即可。新注册账号不写入邮箱字段。旧验证码、邮件登录和邮件重置密码接口已关闭，删除邮件服务依赖与 SMTP 必填配置。
