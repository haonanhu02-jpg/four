## 集成测试覆盖

1. 数据库就绪、未登录访问、参数校验、非法 JSON 和统一错误响应。
2. 邮箱注册、密码与验证码摘要存储、Cookie 会话及退出失效。
3. 两个账号的统计隔离；跨账号挂接上级目标被数据库拒绝。
4. 同一版本并发更新仅一方成功，版本递增；进度/日期约束和重复操作唯一性。
5. 跨站写请求拒绝、错误密码不能登录。
6. 验证码登录、一次性消费、60 秒重发限制。
7. 验证码过期与连续错误上限。
8. 重置密码后旧会话和旧密码失效，新密码可用。
9. 重复运行迁移不重复创建结构。
